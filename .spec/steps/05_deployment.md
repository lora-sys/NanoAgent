# 部署指南

## 阶段 ID
stage_5

## 描述
部署和交付

## 成功标准
成功标准：
- [ ] 页面可通过公开链接或本地服务器成功访问，无 404 错误
- [ ] 在主流浏览器（Chrome, Safari, Edge）及移动端设备上显示正常，无布局错乱
- [ ] 页面加载时间不超过 3 秒，且控制台无报错信息
- [ ] 所有交互元素（按钮、链接、表单）功能正常，跳转准确
- [ ] 代码已完成压缩优化，且敏感信息（如 API 密钥）已移除或隐藏

边界约束：
### Always (必须做)
- 提供分步明确的部署操作指令
- 确保部署环境启用 HTTPS 安全协议
- 在交付前验证所有外部链接的有效性
- 确保代码仓库中不包含任何硬编码的敏感凭证
- 提供部署失败时的回滚或排查建议

### Ask First (先询问)
- 确认用户偏好的托管服务平台（如 Vercel、Netlify 或传统服务器）
- 询问是否需要绑定自定义域名及其 DNS 配置权限
- 确认页面是否依赖特定的后端接口或环境变量

### Never (绝对禁止)
- 禁止在前端代码中明文存储私钥或数据库密码
- 禁止在未获得用户确认的情况下自动执行部署操作
- 禁止使用未经授权的第三方素材或字体

交互提示：
为了顺利完成部署，请告诉我您偏好的托管平台（如 Vercel、Netlify 或自有服务器），是否已准备自定义域名，以及该页面是否需要连接后端 API 服务？
