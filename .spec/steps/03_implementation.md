### Ask First (先询问)
- 确认首选的技术栈（如 React、Vue 或原生 HTML/CSS/JS）
- 确认是否已有品牌 Logo 矢量文件或特定字体要求
- 确认是否需要对接具体的后端 API 接口或仅需静态展示

### Never (绝对禁止)
- 禁止在代码中硬编码任何 API 密钥或敏感信息
- 禁止使用已废弃的 HTML 标签或 CSS 属性
