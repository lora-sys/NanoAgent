# 大纲规划

## 阶段 ID
stage_1

## 描述
明确需求和目标

## 成功标准
成功标准：
- [ ] 商业计划书大纲包含至少 6 个核心章节（如执行摘要、市场分析、商业模式等）。
- [ ] HTML 原型结构图明确列出页面所需的关键区块（如导航、英雄区、功能展示、页脚）。
- [ ] 大纲内容需体现'GreenEnergy'的可持续能源品牌定位。
- [ ] 获得用户对大纲结构的确认反馈后方可进入下一阶段。

边界约束：
### Always (必须做)
- 专注于大纲结构而非完整内容撰写。
- 确保所有规划内容围绕'GreenEnergy'的可持续能源主题。
- 商业计划书大纲需符合行业标准结构。
- HTML 原型规划仅需定义语义化标签结构。
- 使用清晰的分层列表展示规划内容。

### Ask First (先询问)
- 询问公司具体的能源细分领域。
- 询问目标受众群体。
- 询问展示页面的主要转化目标。

### Never (绝对禁止)
- 禁止在本阶段生成完整的商业计划书正文。
- 禁止编写包含复杂 CSS 或 JavaScript 功能的完整代码。
- 禁止虚构具体的财务数据或未经确认的技术参数。

交互提示：
为了制定精准的大纲，请告诉我：1. GreenEnergy 具体专注哪种绿色能源技术？2. 这份商业计划书的主要读者是谁（投资人/内部团队）？3. 展示页面最希望用户完成什么动作？
