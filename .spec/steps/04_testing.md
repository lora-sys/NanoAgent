# 测试计划

## 阶段 ID
stage_4

## 描述
测试和验证

## 成功标准
成功标准：
- [ ] 页面在 Chrome、Firefox 及 Safari 主流浏览器上无布局错位且功能正常
- [ ] 所有交互组件（按钮、表单、导航）通过点击测试，无控制台报错
- [ ] 页面加载时间在标准网络环境下不超过 3 秒，性能评分高于 85 分
- [ ] 视觉设计严格遵循'GreenEnergy'环保主题色调，且移动端适配良好
- [ ] 代码通过 W3C 验证，无明显语法错误或安全漏洞

边界约束：
### Always (必须做)
- 必须提供完整可运行的 HTML/CSS/JS 代码结构
- 必须确保所有图片资源使用开源免费或占位符链接
- 必须包含基本的 SEO meta 标签及无障碍访问属性（alt 文本）
- 必须对核心功能代码添加清晰的注释说明
- 必须验证页面在不同分辨率下的响应式表现

### Ask First (先询问)
- 是否有现有的品牌 Logo 文件或特定色值需要提供？
- 是否需要集成特定的第三方脚本（如统计工具、地图 API）？
- 目标用户主要使用的设备类型是移动端还是桌面端？

### Never (绝对禁止)
- 绝对禁止在代码中硬编码任何真实的 API 密钥或敏感个人信息
- 绝对禁止使用未经授权的付费字体、图片或有版权风险的素材
- 绝对禁止生成包含恶意脚本、挖矿代码或隐蔽追踪器的内容

交互提示：
为了制定更精准的测试方案，请确认您是否有特定的品牌素材（如 Logo、标准色值）需要集成，以及希望重点测试哪些交互功能（如联系表单、数据图表展示）？
