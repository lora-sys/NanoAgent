# 发布准备

## 阶段 ID
stage_4

## 描述
测试和验证

## 成功标准
成功标准：
- [ ] 商业计划书涵盖执行摘要、市场分析、运营模式、财务预测四大核心模块。
- [ ] HTML 原型代码完整，包含<!DOCTYPE html> 声明且能在主流浏览器中无误渲染。
- [ ] 展示页面视觉风格统一，采用符合“绿色能源”主题的配色方案（如绿色、白色）。
- [ ] 所有交付文本无明显拼写错误，财务数据均标注为预估值。

边界约束：
### Always (必须做)
- 确保商业计划书逻辑连贯，数据推导合理。
- 提供完整的 HTML 文件代码，而非片段。
- 在代码中使用占位符代替未提供的具体图片资源。
- 明确区分事实陈述与预测性声明。
- 保持语气专业、积极且符合初创公司定位。

### Ask First (先询问)
- 确认是否需要在 HTML 页面中植入具体的社交媒体链接或联系表单。
- 询问用户是否希望商业计划书包含特定的竞争对手分析。
- 确认交付的商业计划书是否需要特定的格式标记（如 Markdown 标题层级）。

### Never (绝对禁止)
- 禁止使用受版权保护的真实图片链接作为占位符。
- 禁止生成包含恶意脚本或外部不安全引用的代码。
- 禁止承诺具体的投资回报率或保证性的财务结果。

交互提示：
在最终生成之前，请确认您是否需要在展示页面中嵌入具体的联系方式（如邮箱、电话），以及商业计划书是否有特定的篇幅或侧重点调整需求？
